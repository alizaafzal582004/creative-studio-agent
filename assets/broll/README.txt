YOUR B-ROLL FOLDER
==================

Put videos (mp4, mov, webm) or images (jpg, png) in this folder.
The FILE NAME says what the footage shows. The AI picks files by name.

Examples:
  money.mp4
  sign_language.mp4
  teachers_classroom.mp4
  family_dinner.jpg          (images get a slow zoom automatically)
  office/meeting_01.mp4      (sub-folder names count too: "office meeting")

Where to get footage:
  - Mixkit  (mixkit.co)  : free, usually no attribution required
  - Videvo  (videvo.net) : license varies per clip, check before downloading
  - Pixabay / Pexels, downloaded by hand from their websites
  - Your own footage (best option, no licensing questions)

You are responsible for the license of any footage you add: only use footage you are allowed to use in videos.
